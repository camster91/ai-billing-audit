{# Bulk action confirmation modal (kanban t_7e558a6a). Invoked from the dashboard when a biller clicks a destructive bulk control ("Dismiss 47 findings on rule MOD-25", "Flag 30 encounters", "Accept 25+ encounters"). The modal calls /api/bulk/confirm first; the backend's bulk_confirm_validate enforces: * action in {accept, dismiss, flag} * 1..500 encounter_ids * type "confirm" for dismiss/flag actions and for 25+ item accepts On success, the actual /encounters/bulk-{accept,dismiss,flag} endpoint is called. On failure, the modal stays open and shows the error message. The template is hidden by default; openBulkConfirmModal() in dashboard.js toggles [hidden]. Backdrop click and Esc close the modal (handled via [data-action="modal-close"] delegation in the existing modal handler). Destructive actions (dismiss / flag) require the user to type the literal "confirm" before the Confirm button enables — this mirrors the tenant-delete confirmation pattern. #}
