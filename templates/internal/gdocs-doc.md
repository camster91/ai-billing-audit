# Google Docs — internal document template

> Specification for the Zorva internal-doc Google Docs template.
> Use this for written reports: weekly status, post-mortems,
> RFCs, vendor evaluations.

## Structural outline

```
[Page header — navy band, Zorva logo]

TITLE:   {Document title — H1, Inter Bold 32pt}
SUBTITLE:{Subtitle or one-line summary — Inter Regular 14pt, muted}

META BLOCK (1×3 table, navy-on-white):
  | Author        | Date         | Status                |
  | {your name}   | {YYYY-MM-DD} | {Draft / Review / Final}|

TOC:   Table of contents (auto-generated by Google Docs)

─────────────────────────────────────────────────────
H2: Summary
  One-paragraph executive summary (3–5 sentences). Bold the
  one-line takeaway. This is what busy readers will actually read.

─────────────────────────────────────────────────────
H2: Background
  Why this doc exists. The decision it supports. The audience.

─────────────────────────────────────────────────────
H2: Findings / Body
  Numbered subsections (H3). Use bullet lists. Bold key
  numbers inline. Cite sources with hyperlinks, never footnotes.

  Example callout box:
  ┌────────────────────────────────────────────────┐
  │  $2.4M missed revenue — Q3 2026                  │  ← accent border
  │  Source: Zorva audit log, 14 tenants, 90 days.   │
  └────────────────────────────────────────────────┘

─────────────────────────────────────────────────────
H2: Recommendation
  Numbered list (1, 2, 3). One action per item. Each item
  should have an owner and a deadline.

─────────────────────────────────────────────────────
H2: Open questions
  Bulleted list of unresolved items. Each ends with a
  parenthetical owner:  (Cameron)

─────────────────────────────────────────────────────
H2: Appendix
  Supporting tables, raw data, references. Linked from the
  body sections with "see Appendix A" anchors.

─────────────────────────────────────────────────────
[Page footer — muted gray, "zorva.health · page N"]
```

## Placeholders

| Slot          | Required | Example                                |
| ------------- | -------- | -------------------------------------- |
| Document title| yes      | "Q3 2026 Revenue-cycle audit — findings" |
| Subtitle      | yes      | "What we shipped, what we learned, what's next" |
| Author        | yes      | "Cameron Ashley"                       |
| Date          | yes      | "2026-09-30"                           |
| Status        | yes      | "Draft" / "Review" / "Final"           |
| Audience      | optional | "Exec team + finance"                  |

## Brand styling

Apply these styles manually in Google Docs (or set them on the
template so they're inherited by every new doc):

| Style          | Font       | Size | Color        | Weight  |
| -------------- | ---------- | ---- | ------------ | ------- |
| Title (H1)     | Inter      | 32pt | `#0F172A`    | Bold    |
| Subtitle       | Inter      | 14pt | `#94A3B8`    | Regular |
| H2             | Inter      | 22pt | `#0F172A`    | SemiBold|
| H3             | Inter      | 16pt | `#0F172A`    | SemiBold|
| Body           | Inter      | 11pt | `#1F2937`    | Regular |
| Caption        | Inter      | 9pt  | `#94A3B8`    | Medium  |
| Callout border | (border)   | 1pt  | `#5EEAD4`    | n/a     |

**Page setup:**
- Margins: 1" top/bottom, 0.75" left/right
- Page size: Letter (US) or A4 — pick whichever the team uses
- Page header: 0.5" navy band, white logo, transparent body

## Duplication steps

1. Open the master template: `templates/internal/master-gdocs-doc.gdoc`
   (lives in the shared Zorva drive under `Branding/Masters/`).
2. File → Make a copy.
3. Rename with the project prefix:
   `[Project] – [Doc title] — [YYYY-MM-DD]`.
4. Update the META BLOCK with author / date / status.
5. Replace placeholders in body sections.
6. Add to the relevant Drive folder (`/Zorva/Reports/`,
   `/Zorva/RFCs/`, etc).
7. Share with the audience listed in META.
