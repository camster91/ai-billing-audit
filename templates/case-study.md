## Anonymization rules

- **Clinic name:** never use the real clinic name in the published
  case study. Use a generic identifier like "Solo family-medicine
  practice in Red Deer, AB" or "[Anonymized Clinic]".
- **Provider names:** use first name and last initial only (e.g.
  "Dr. Maria L."), or a role title (e.g. "Lead physician").
- **Patient identifiers:** none. The auditor works on hashed
  patient IDs, so the source data should not contain real names,
  PHNs, or DOBs in the first place.
- **Real dollar figures:** allowed. The number is the point. If the
  clinic prefers an anonymized range, use a banded number (e.g.
  "$15K–$20K recovered") and say so.
- **Direct quotes:** get written permission from the named biller or
  clinic contact before publishing. The signed quote release lives
  in the customer file.
